    System architecture

    How the proposed system processes a job description and resumes from input to candidate ranking.

    1. InputEnter job description and upload resumes
    →
    2. Resume processingRead resume content and identify candidate information
    →
    3. MatchingCompare resume information with job requirements
    →
    4. ScoringCalculate a relevance score for each candidate
    →
    5. RankingDisplay candidates in ranked order with score details
